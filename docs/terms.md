Circuit Playground MakeCode is an independent, unofficial open-source project.
It is provided without warranty under the licenses included with its source

Programming and replacing firmware can make a board temporarily unresponsive.
Keep the documented UF2 recovery path available, use firmware intended for the
exact board model, and do not disconnect power while a bootloader update is in
progress.
