# Privacy

Circuit Playground MakeCode stores browser projects locally on the device.
The self-hosted editor does not provide its own user-account or project
database service.

Optional features such as sharing, GitHub integration, and installing external
packages can contact Microsoft, GitHub, or the package host when the user
chooses them. Those services apply their own privacy policies. Built-in
editing, simulation, and cached firmware do not require those optional
services after the static editor has loaded.
